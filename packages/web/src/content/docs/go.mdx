Run real OpenAI and Anthropic frontier models through PhysicsCode, billed
against your PhysicsCode account credit at the vendor's real pricing —
instead of bringing your own OpenAI/Anthropic API key.

:::note
This depends on the server operator having configured vendor API keys. If
they haven't yet, selecting one of these providers returns a
`provider_not_configured` error.
:::

---

## How it works

1. Log in with `physicscode account login` (or `/connect` in the TUI).
2. Select **PhysicsCode Credit (OpenAI)** or **PhysicsCode Credit
   (Anthropic)** — no separate API key to paste, it uses your logged-in
   account.
3. Run `/models` to see what's available (for example
   `physicscode-openai/gpt-5.6`, `physicscode-anthropic/claude-opus-4-8`).

---

## Guardrails

Since this spends real money at real vendor rates, two limits apply on top of
the normal per-token billing:

- Requests stop once your credit balance reaches zero.
- A single request estimated to cost more than a configured per-request limit
  is rejected before it's sent, rather than after.

Check your balance and usage history in the account portal's Billing tab.

---

## Bring your own key

You don't need PhysicsCode credit to use OpenAI or Anthropic models — you can
always configure your own API key for the regular `openai`/`anthropic`
providers instead. See [Providers](/docs/providers) for details.
