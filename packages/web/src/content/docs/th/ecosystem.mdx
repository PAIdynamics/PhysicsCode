ชุดโครงการชุมชนที่สร้างขึ้นบน PhysicsCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ PhysicsCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-physicscode](https://github.com/awesome-physicscode/awesome-physicscode) และ [physicscode.cafe](https://physicscode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน

---
