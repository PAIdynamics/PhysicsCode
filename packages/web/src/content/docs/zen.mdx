**PAI Dynamics Hosted** is PhysicsCode's built-in, no-setup model provider. Log
in with your PhysicsCode account and start using it — no separate API key, no
signup beyond your PhysicsCode login, and no cost by default.

---

## How it works

1. Run `physicscode account login` (or `/connect` in the TUI and select **PAI
   Dynamics Hosted**).
2. That's it. `paidynamics` is the default provider — you don't need to pick a
   model to get started.

Run `/models paidynamics` (or `physicscode models paidynamics`) to see what's
currently being served. PhysicsCode discovers the model list live from the
hosting server, so this reflects whatever checkpoint is actually running —
it's not a fixed, hardcoded list.

---

## Pricing

Usage is billed against your PhysicsCode account credit. The per-token rate is
set by the server operator (`PAI_INPUT_USD_PER_MILLION` /
`PAI_OUTPUT_USD_PER_MILLION` in the Worker config) and defaults to **free**.
Check your balance and usage history in the account portal's Billing tab.

---

## Bring your own key

PAI Dynamics Hosted is optional — you can configure any other provider
(OpenAI, Anthropic, or a custom endpoint) instead, or alongside it. See
[Providers](/docs/providers) for the full list.
